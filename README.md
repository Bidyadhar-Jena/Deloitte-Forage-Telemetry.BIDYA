## Deloitte Forage Telemetry Data Transformation Project

## Overview

This project is a solution for the Deloitte Forage virtual internship task.
The objective of the project is to convert telemetry data from two different JSON formats into a single unified structure.

## Features

- Conversion from Format 1 to unified format
- Conversion from Format 2 to unified format
- ISO 8601 timestamp conversion to milliseconds since epoch
- UTF-8 encoding support for Unicode characters
- Automated unit testing using Python unittest

## Project Files

- "main.py" → Main Python program containing conversion logic and tests
- "data-1.json" → Telemetry data in Format 1
- "data-2.json" → Telemetry data in Format 2
- "data-result.json" → Expected unified output format

## Technologies Used

- Python 3
- JSON
- unittest module
